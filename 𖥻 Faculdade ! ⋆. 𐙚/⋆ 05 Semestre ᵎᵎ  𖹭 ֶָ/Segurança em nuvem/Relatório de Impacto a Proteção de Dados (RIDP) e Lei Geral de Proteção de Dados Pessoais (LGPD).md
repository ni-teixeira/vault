# Relatório de Impacto a Proteção de Dados (RIDP)

## Conceito
É um documento formal que avalia os riscos associados ao tratamento dos dados pessoais, detalhando as medidas de segurança adotadas para minimização desses riscos

Assegura que o tratamento de dados está de acordo com a LGPD, protegendo os direitos e liberdade dos titulares.

## Papeis e responsabilidades
### Titular
Pessoa natural a quem se refere os dados pessoais (que são objetos de tratamento)

### Controlador
Pessoa natural ou jurídica, de direito público ou privado, a quem competem as decisões referentes ao tratamento de dados pessoais

### Operador
Pessoa natural ou jurídica, de direito público ou privado, que realiza o tratamento de dados pessoais em nome do Controlador
Deve manter os registros de todas as operações realizadas com os dados

### Encarregado
Pessoa natural, indicada pelo Controlador, que atua como canal de comunicação entre o Controlador e os Titulares e a Autoridade Nacional
Responde legalmente pelo cumprimento das regras previstas na lei
Acolhe reclamações de Titulares e presta esclarecimentos necessários
Divulga ocorrências e vazamentos que comprometam Dados Pessoais

## Necessidade
### Tratamento de dados sensíveis
Quando o tratamento envolve dados como informações de saúde, origem racial etc
### Grande escala
Quando operações tratam dados pessoais em grande volume
### Novas tecnologias
Novas tecnologias aplicadas ao tratamento de dados podem aumentar riscos a privacidade

### Exemplos
#### Tratamento de dados de Saúde
Um hospital que deseja compartilhar dados de pacientes com uma empresa de pesquisa clínica para desenvolver novos medicamentos. Como os dados de saúde são sensíveis e envolvem um grande número de pessoas, **o RIDP é necessário para garantir que os riscos à privacidade sejam minimizados**

#### Monitoramento de funcionários em grande escala
Uma empresa de logística que pretende implantar um sistema de monitoramento por GPS nos veículos de entrega para acompanhar a localização dos motoristas em tempo real. **O monitoramento contínuo dos funcionários em grande escala pode gerar riscos significativos à privacidade, exigindo a elaboração de um RIDP**

#### Uso de Reconhecimento Facial em Espaços Públicos 
Uma prefeitura decide **implementar câmeras com reconhecimento facial em praças e terminais de ônibus** para melhorar a segurança pública. Como envolve vigilância em massa e o tratamento de dados biométricos, que são altamente sensíveis, o RIDP é essencial para avaliar os impactos e proteger os direitos dos cidadãos.

#### Análise de Crédito com Algoritmos Avançados 
Uma fintech desenvolve um algoritmo para análise de crédito que coleta e processa uma grande quantidade de dados pessoais, incluindo informações financeiras, hábitos de consumo e histórico de pagamento. Dado o potencial impacto negativo sobre os titulares (como a possibilidade de discriminação ou erro), o RIDP deve ser elaborado.

#### Implantação de Dispositivos de IoT em Residências 
Uma empresa de tecnologia lança um novo sistema de automação residencial que coleta dados sobre o comportamento dos moradores, como horários de uso de dispositivos e padrões de movimento dentro de casa. Como esses dados podem revelar informações sensíveis sobre os hábitos e a privacidade dos usuários, é necessário um RIDP para avaliar e mitigar os riscos.
