# Características dos processadores:

## O que é CPU?

Unidade central de processamento.

O soquete é o tipo de conexão física que o processador usa pra se conectar na placa mãe.

Como se fosse uma tomada onde a cpu esta se conectando a placa mãe

## Clock:

O clock interno é o número de ciclos por segundo de um sinal que esta sendo usado dentro do processador.

Podemos resumir como o ritmo do coração que está batendo em ciclos por segundo.

### Overclock dinamico:

É como forcar para que o processador fique mais rápido.

### Núcleos:

São como os músculos, quanto mais núcleos teremos mais forcas para fazer varias coisas ao mesmo tempo.

### Relação com binário:

Cada pulso de clock um dado pode ser transmitido, aumentando-se a frequência do clock, aumenta-se a velocidade com que os dados são transmitidos.
