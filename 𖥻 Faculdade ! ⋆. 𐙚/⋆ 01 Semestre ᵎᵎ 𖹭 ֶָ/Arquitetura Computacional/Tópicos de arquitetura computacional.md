# O que é um computador:

É uma máquina capaz de processar dados e realizar cálculos.

Ele é composto por

1. CPU (cérebro do computador)
2. Memória (onde os dados e as instruções são armazenados temporariamente)
3. Dispositivos de entrada e saída

### Microcontrolador

É um sistema completo em um único chip

Contém:

- CPU
- Memória ROM e RAM
- Portas de entrada e saída

Imagine um microcontrolador como um chef que não só cozinha, mas também faz as compras e cuida da cozinha, tudo sozinho.

### Microprocessador

É a CPU dentro de um chip, que depende de outros componentes (como memoria externa) para funcionar.

Ideal para tarefas mais complexas e rápidas.

Nesse caso, ele é o chef principal de um restaurante, coordenando vários ajudantes para diferentes tarefas.

# CPU:

Unidade Central de Processamento

É a parte do computador que realiza cálculos e processa as instruções.

É dividida em duas partes principais:

- ULA (Unidade Lógica e Aritmética): Executa operações de matemáticos e lógicos.
- UC (Unidade de Controle): Coordena todas as operações dentro do processador e “manda” quando cada instrução deve ser executada.

Dentro da CPU também temos registradores, que são pequenas memorias internas que armazenam dados temporários

- Acumulador: Armazena resultados de operações.
- Contador de Programa(PC): Aponta para o próximo endereço de instrução a ser executada.
