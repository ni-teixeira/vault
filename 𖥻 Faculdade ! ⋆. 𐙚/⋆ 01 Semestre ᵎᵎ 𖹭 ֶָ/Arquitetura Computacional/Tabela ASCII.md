## ASCII:

American Standard Code for Information Interchange – código padrão americano para troca de informações

Cada caractere ASCII tem 8 bits. Porém, como os computadores são orientado a byte, cada **caractere ASCII é armazenado em um byte separado**

## **Como funciona?**

**→ Cada caractere tem um código:** Cada letra maiúscula, minúscula, número, símbolo de pontuação e até mesmo comandos especiais têm um código numérico único associado a ele.

**→ Código binário:** Esses códigos numéricos são representados em binário (zeros e uns), a linguagem que os computadores entendem.

**→ Padronização:** O ASCII permite que diferentes computadores se comuniquem, pois todos usam o mesmo padrão para representar os caracteres.
