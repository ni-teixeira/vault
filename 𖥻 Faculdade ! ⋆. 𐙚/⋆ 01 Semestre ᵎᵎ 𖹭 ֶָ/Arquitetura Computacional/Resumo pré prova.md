# Definição de um computador:

Podemos definir um computador como uma maquina que **ajuda a resolver problemas** seguindo **conjuntos de passos.**

Hoje podemos dividir os dispositivos eletrônicos que estão dentro do computador como:

→ Entrada;

→ Processamento;

→ Saída;

→ Armazenamento.

# Correlação com Arquitetura Computacional:

Um sistema computacional é um conjunto de componentes que estão integrados para funcionar como uma única coisa.

Seu objetivo é realizar algum tipo de **operação com os dados** para obter informações.

Como temos uma grande diversidade de computadores, eles podem ser divididos nas seguintes categorias:

### Âmbito geral:

→ Capazes de desempenhar diversas tarefas;

→ Usados em escritórios, escolas e casas.

### Âmbito especifico:

→ Desenhados para desempenhar tarefas reduzidas;

→ Utilizados em mecanismos industriais e cálculos científicos.

### Utilização:

→ **Científico**: dirigido a áreas de calculo e pesquisa, tem pouco volume de entrada e saída de dados.

→ **Comercial**: grande maioria dos equipamentos nas empresas, comportam um grande volume de entrada e saída de dados.

# Hardware:

É toda a **parte física** de um computador, componentes eletrônicos e periféricos internos e externos.

### Hardware interno:

São as pecas do PC que são necessárias para seu funcionamento, como: placa mãe, memoria ram e fonte.

# Software:

Toda a **parte programável de um sistema** é considerado um software, como os SOs, aplicativos ou linguagens de programação.

# Firmware:

Um software que é desenvolvido em linguagem de baixo nível que faz o **gerenciamento do hardware,** como a bios.

## Como ocorrem essas interações?

→ Cada família de processadores tem um conjunto de instruções que é capaz de executar.

→ É representada por uma sequencia de bits. Cada bit pode assumir o valor de 0 ou 1.

→ **Dentro de um byte cabem 8 bits**.
