# O que é?

É uma técnica utilizada para conhecer a regra de negocio, projetar o banco de dados e contribuir para o compartilhamento dos dados.

# Tipos de banco de dados:

### Modelo hierárquico:

→ Representação hierárquica dos dados como pai e filho;

→ São estruturados em arvores;

→ Associação entre dois registros.

![image.png](https://prod-files-secure.s3.us-west-2.amazonaws.com/e624adb6-6bef-46e2-ba7b-89e68d32f796/273b7173-ae07-4a2a-bbea-0475c8236b99/image.png)

### Modelo em rede:

→ Um registro pode estar envolvido em varias associações;

→ É representado como grafos.

![image.png](https://prod-files-secure.s3.us-west-2.amazonaws.com/e624adb6-6bef-46e2-ba7b-89e68d32f796/b0166762-3085-41ec-a61b-ccb3e54e861e/image.png)

### Modelo relacional:

→ Surgiu para aumentar a independência dos dados;

→ Flexível para solucionar vários problemas;

→ Relação é constituída por um ou mais atributos.

![image.png](https://prod-files-secure.s3.us-west-2.amazonaws.com/e624adb6-6bef-46e2-ba7b-89e68d32f796/ab2f0eca-c9ce-4ff7-99dd-86aa86e6ced7/image.png)

### Modelo orientado a objetos:

→ Surgimento foi motivado em função dos limites de armazenamento e representações semânticas;

→ Uso de linguagens de POO;

→ Representados por diagramas UML.

# Principais conceitos:

### DDL (Data Definition Language)

Instruções do SQL para criar, alterar ou eliminar tabelas.

**(CREATE, ALTER, DROP)**

### DML (Data Manipulation Language)

Instruções do SQL para inserir, atualizar, excluir, consultar os dados.

**(INSERT, UPDATE, DELETE, SELECT)**

### DCL (Data Control Language)

Lidar com os direitos e permissões.

→ **GRANT**: concede privilégios de acesso ao usuário.

→ **REVOKE**: retira privilégios de acesso ao usuário usando o comando Grant.
