## Abstração

A abstração é um conceito que envolve simplificar a complexidade, focando nos aspectos mais relevantes de um objeto ou ideia, enquanto ignora detalhes desnecessários

Aplicação

Interface

SO

Hardware

**Aplicativos** → Interface bonita → **Sistema operacional** → Interface feia → **Hardware**

É necessária para manter as coisas simples

→ Esconder ou não mostrar algo

O papel do SO é abstrair algumas coisas para simplificar o processo

Tem como objeto de facilitar a vida do usuário.

Hardware → Abstração → Programas

## HAL

**Hardware Abstraction Layer**

É feito para traduzir alguns hardwares

É como se fosse o google tradutor

→ É um software que trabalha entre o hardware e app que **chama o hardware**
