# Proto persona

- Personas nos fornecem uma forma precisa de pensar e comunicar sobre como os usuários se comportam, como eles pensam, o que desejam realizar, por quê.
- Eles são arquétipos feitos à base de dados comportamentais obtidos a partir dos muitos usuários reais encontrados em entrevistas etnográficas.

## Tipos de persona

_**Baseada em dados**_

→ São criadas a partir da analise de dados conforme o uso do usuário no software

→ Utiliza dados comportamentais e não características

→ Permite criar experiencias iguais a partir de diferentes comportamentos

→ Permite identificar comportamentos iguais de acordo com pessoas diferentes

_**Baseadas em pesquisa**_

→ Não são inventadas

→ Representa um grupo de pessoas e não apenas um usuário especifico

→ Traz caracteristicas de um publico pesquisado

→ Pode usar netnografia (pesquisa em redes sociais)

→ Identifique os utilizadores e defina uma persona para cada um

## Como criar?

- Realize uma pesquisa com os concorrentes
- Anote os principais pontos identificados nos usuarios para cada quadrante (dores, necessidades, informações, comportamentos)
- Agrupe por similaridade
- Complemente os detalhes que faltam
- Escreva tudo nos quadrantes

# Jornada do usuário

→ Representa o processo que um usuário tem ao interagir com um produto ou software

→ Desde o primeiro contato até o objetivo final, seja ela a realização de uma tarefa, a resolução de um problema ou a obtenção de informações

# Pesquisa

É a etapa mais importante de um projeto que envolve UX e UI

É importante ter em mente que existe uma diferença muito grande entre o que as pessoas fazem e o que elas dizem que fazem

→ Priorize o que as pessoas REALMENTE fazem

“A pesquisa de usuário é conduzida para entender as características, objetivos e comportamentos dos usuários. O objetivo é produzir designs que melhorem as práticas de trabalho e as vidas das pessoas.”

# Técnicas de pesquisa

Toda pesquisa começa com um **problema** ou **pergunta**

Podemos usar a técnica How Might We para elaborar perguntas e realizar nossas pesquisas

“Como podemos melhorar a navegação e busca na plataforma para que os usuários encontrem mais facilmente o que procuram?”

### Desk Research

É uma técnica de pesquisa de baixo custo que envolve a coleta de dados a partir de fontes secundárias que estão disponíveis publicamente

Ex: relatórios, livros, artigos e internet

### Netnografia

Tem uma abordagem qualitativa e envolve a observação e analise das interações dos usuarios dentro de redes sociais, foruns, comentarios em sites etc.

### Benchmarking

- Defina os objetivos – O que você pretende alcançar? (Padrão visual, conteúdo, fluxo de uso, ...)
- Identifique os concorrentes – Liste os concorrentes em um ranking por similaridade.
- Analise as interfaces – Observe o fluxo de uso, os elementos de design, navegação e interações.
- Pesquise os feedbacks dos usuários – O que os usuários dos concorrentes estão falando sobre eles (Veja o Reclame aqui, Lojas de aplicativos, etc).
- DOCUMENTE TUDO!
