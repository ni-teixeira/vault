# Arquitetura da informação

Podemos imaginar um site como se fosse uma casa e suas páginas sendo os comodos. Com isso, os **usuários podem chegar em qualquer lugar**

![[Pasted image 20260909153519.png]]
![[Pasted image 20260909153523.png]]

Por isso, precisamos garantir que o usuário consiga realizar sua tarefa independentemente do ponto em que entrou no site.

Evite o usuário de pensar:

- Onde estou?
- Como vim parar aqui?
- Como faço para encontrar a funcionalidade que procuro?
- Como vou para a página que preciso?
- Que site horrível, vou procurar outro!

# Wireframes

Para isso, construímos wireframes

Também são chamados de protótipos de baixa fidelidade, são utilizados para projetar a experiência de navegação do usuário, com **foco no fluxo da navegação.**

→ O objetivo principal é projetar uma **experiencia simples, intuitiva e completa**

![[Pasted image 20260909153529.png]]
Não construir wireframe aumenta a chance do trabalho não ter sucesso e precisar refazer

# Grids e design responsivo

Precisamos adaptar as interfaces de acordo com a diversidade de tamanhos de tela

### Layouts responsivos

Se refere a pratica de criar interfaces que se ajustam de maneira dinamica e adequada a diferentes tamanhos de tela

### Grids

São sistemas de layout que dividem a sua interface em colunas, facilitando a organização e alinhamento dos elementos na tela

Existem diversos tipos de grids e eles podem variar de acordo com o framework que você escolheu.

![[Pasted image 20260909153538.png]]

O que diferencia os layouts de acordo com a tela são os breakpoints, que são criados com os media queries.

# UX Writing

É uma pratica do design que foca em criar os textos de uma interface que sejam claros e eficientes.

### Dicas

→ Defina o tom de voz

→ Seja consistente

→ Seja conciso

→ Deixe o conteudo facilmente escaneavel

![[Pasted image 20260909153549.png]]

→ Evite negação e termos negativos

![[Pasted image 20260909153553.png]]

→ Comece com o objetivo da ação

![[Pasted image 20260909153558.png]]

→ Cuidado com o uso de palavras estrangeiras

![[Pasted image 20260909153603.png]]

→ Evite girias, abreviações, regionalismo

![[Pasted image 20260909153607.png]]

→ Oculte pronomes pessoais ou artigos quando possível

![[Pasted image 20260909153616.png]]

→ Evite referencia a gênero

![[Pasted image 20260909153620.png]]

### Microcopy

São as interações textuais que acontecem através dos elementos e componentes da interface, como:

- Botões
- Hyperlinks
- Inputs
- Notificações

### Dicas

→ Utilize menos palavras possíveis

→ Letras iniciais maiúsculas em botões
