# Roteamentos

O serviço de roteamento permite que o roteador analise os caminhos e **escolha o seu caminho de preferencia** para enviar pacotes a um determinado destino.

O roteamento de Redes é o **processo** de seleção de caminhos, de uma ou mais redes.

→ Age como o Waze/Google Maps

→ IP e roteamento trabalham em conjunto

O gateway de internet serve como um portal entre duas redes.

Esse tipo de ferramenta serve para intermediar a troca de dados entre as redes. O roteador consegue fazer esse papel, conectando os dispositivos a internet.
