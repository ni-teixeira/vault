## O que é uma linguagem de programação?

→ É composta por palavras-chaves que são convertidas em instruções. Cada instrução é traduzida para outra linguagem.

## Quais são os tipos de linguagem?

### Baixo nível

→ Mais próxima do hardware, instruções simples

→ Dependente do processador

→ Programação complexa

### Alto nível

→ Não é tão dependente do hardware, instruções mais complexas

→ Próximas da linguagem humana

→ Fortemente ligada ao SO

## Compiladores

Analisa o programa de linguagem de alto nível, verificando se não há erros sintáticos e se não há instruções escritas de forma errada

Se não tiver erro, é gerado o programa equivalente em linguagem de baixo nível

O código pode ser executado varias vezes sem a necessidade de compilar novamente

## Interpretador

Interpreta e executa o programa escrito em linguagem de alto nível sem gerar um programa em baixo nível

Analisa os erros sintáticos

Toda vez que for executado, é feita uma nova analise, o que deixa a execução mais demorada

Programa de alto nível → interpretador → execução do programa

## Modelo hibrido

Programa (java) que passa por compilação e interpretação

## IDE

Ambiente de desenvolvimento integrado

Editor de texto, compilador, depurador e ambiente de execução
