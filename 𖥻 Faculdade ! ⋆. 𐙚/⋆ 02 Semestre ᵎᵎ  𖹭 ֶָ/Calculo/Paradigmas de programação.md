# _O que são paradigmas da programação?_

Os paradigmas da programação são formas que podemos abordar a resolução de problemas quando estamos escrevendo um código, cada linguagem tem seu próprio padrão e conjunto de regras que os desenvolvedores precisam seguir como guia. Além disso, esses paradigmas definem as regras do que não deve ser feito no código.

No universo da programação, existem dois paradigmas fundamentais que moldam a forma como desenvolvemos software: o Imperativo e o Declarativo. Cada um desses paradigmas representa uma forma distinta de como abordar a resolução de problemas através do código. O imperativo abrange a programação estruturada e a programação orientada a objetos, já o declarativo abrange a programação funcional e lógica.

### _Paradigma imperativo:_

Este tipo de paradigma é um jeito de programar que tem como objetivo principal dar instruções claras sobre a realização das tarefas. Podemos usar como exemplo uma receita de cozinha, onde você segue os passos para preparar um prato.

É usado comandos simples e objetivos como: “atribua o valor da variável y”. Além de podermos tomar decisões ou repetir diversas vezes as ações. Também é muito utilizado as funções para reutilizar os passos e comandos dados.

O paradigma imperativo pode ser usado para tarefas mais práticas, como lidar com dados e interagir com sistemas.

### _Paradigma estruturado:_

Este é um estilo dentro do paradigma imperativo que está focado em organizar o código fonte em sequências, é utilizado em linguagens como COBOL, C, BASIC etc.

São etapas claras e específicas que devemos utilizar dentro do código.

### _Paradigma orientado a objetos:_

Já o paradigma OO é focado na ideia de termos objetos dentro do programa. Cada objeto, instância de classe, vai encapsular atributos e métodos para permitir as interações entre eles e a execução das tarefas. Acaba sendo uma abordagem mais facilitadora para modelagem de sistemas mais complexos para representar entidades.

Existem conceitos chaves dentro deste paradigma, como o encapsulamento, a herança e o polimorfismo. Esses conceitos chaves complementam a característica do paradigma orientado a objeto.

### _Paradigma declarativo:_

Esse paradigma está focado em descrever o que o programa deve alcançar em vez de como alcançá-lo. Não devemos fornecer uma sequência de instruções e sim declarar as propriedades que o resultado final deverá ter.

### _Paradigma funcional:_

A programação funcional está baseada no uso de funções como as partes mais fundamentais de um código, permitindo com que essas funções sejam tratadas de forma mais flexível, como: blocos de construção de funções que podem ser utilizados e armazenados em diferentes partes de um programa.

Uma de suas características é a imutabilidade dos dados, onde uma vez criados, eles não são mais alterados, resultando em um código com resultado mais previsível. Esse paradigma acaba se alinhando ao paradigma declarativo, focando no que deve ser feito e não como deve ser feito. A programação funcional se destaca para solucionar desafios complexos ao combinar a flexibilidade das funções e a imutabilidade dos dados.

Além disso, é importante citar que este tipo de programação utiliza muito a recursividade para abordar os problemas de maneira direta. Pode também aceitar funções de alta ordem, que aceitam ou retornam a outras funções.

### _Paradigma lógico:_

O paradigma lógico se destaca por utilizar a lógica matemática como base fundamental, diferenciando-se dos outros ao empregar regras lógicas para estabelecer relações entre elementos. Neste paradigma, o programador define condições e relações que precisam ser verdadeiras, permitindo que o sistema deduza soluções automaticamente.

# _Quais são os paradigmas da linguagem R e Python?_

A linguagem R é multiparadigma, podendo se encaixar em, por exemplo, orientado a objetos, imperativo e funcional. É uma linguagem dinâmica e fracamente tipada. A linguagem é voltada para análise e visualização de dados.

Python também é uma linguagem multiparadigma, onde suporta a orientação a objetos, programação funcional e procedural. É uma linguagem com tipagem dinâmica e forte.

Cada paradigma tem suas vantagens e desvantagens dependendo do código, a escolha entre eles depende do desenvolvedor, do contexto do projeto e da natureza do problema a ser resolvido.
