## Wireframe

Design de um projeto para o cliente, uma ilustração com desenhos fundamentais (em baixa resolução e preto e branco)

## Protótipo de tela

Desenho da tela e de como ela deve funcionar (em alta resolução)

## Protótipo funcional

## Design de interface

→ É identificado objetos e ações de uma interface e então cria um layout de tela que forma a base de um protótipo de interface

→ O projeto de interface do usuário cria um meio de comunicação efetivo com o computador e o humano

## Dicas para construção de telas

### Agrupamento

Elementos relacionados devem ficar juntos e não relacionados devem ficar separados

### Proximidade dos objetos

Alinhado a esquerda:

→ Menos espaço na vertical, mais espaço na horizontal

→ Demanda mais atenção do usuário

→ Mais lento de preencher

→ Dificuldade para o multilíngue

Alinhado acima:

→ Bom para mobile e responsividade

→ Bom para multilíngue

→ Preenchimento mais rápido

→ Requer mais espaço na vertical

→ Não é bom para formulários longos

### Descrição de label

Rótulos não são textos de ajuda, eles devem ser curtos e objetivos como “senha”

### Hint/texto de ajuda

Adicione popups ou redirecione para outro espaço. Se o texto for curto, use a parte de baixo da input para escrever

### Máscaras e campos default

Evitam erros nos cadastros e ajudam na padronização dos dados. Campos comuns para usuários devem iniciar com um preenchimento padrão

### Usabilidade

Deixar o usuário no comando, reduzir a carga de memoria do usuário e criar uma interface consistente
