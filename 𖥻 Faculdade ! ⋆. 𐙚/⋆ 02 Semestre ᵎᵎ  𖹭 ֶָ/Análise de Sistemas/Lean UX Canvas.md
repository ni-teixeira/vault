→ Metodologia de design que prioriza a experiencia do usuário (UX)

→ Usada para criar produtos digitais e é uma abordagem mais criativa

## Princípios do Lean UX

→ Validar hipóteses

→ Feedbacks rápidos

→ Priorizar a experiência do usuário

## Como funciona?

1. Criar uma hipótese
2. Validar a hipótese
3. Receber feedbacks
4. Tomar decisões
