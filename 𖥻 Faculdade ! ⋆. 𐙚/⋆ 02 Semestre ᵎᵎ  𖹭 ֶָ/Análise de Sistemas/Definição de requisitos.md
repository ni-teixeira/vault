Os requisitos definem o que o software deve fazer, como deve ser e as condições que devem ser atendidas

## Requisitos de usuário

Combinações de requisitos funcionais e não funcionais. Devem ser projetados para serem compreensíveis por usuários leigos

Linguagem natural, diagramas e tabelas

## Requisitos de sistema

Componentes essenciais para o software, descreve recursos, características e restrições que o sistema deve possuir

### Requisitos funcionais

→ Necessidades ou funcionalidades esperadas em um processo ou software

→ É o que _**o sistema deve fazer**_

### Requisitos não funcionais

→ Características que o sistema deve respeitar ao atender requisitos funcionais

→ É _**como o sistema deve fazer**_

## Analise de sistemas

Métodos e técnicas de investigação e especificação da solução de problemas, a partir dos requisitos levantados, para a criação e implementação

### Atuação

→ Gestão de empresas

→ Facilitadores dos processos internos e externos

→ Qualidade, produtividade, e inovação

→ Lucrativa e competitividade empresarial
