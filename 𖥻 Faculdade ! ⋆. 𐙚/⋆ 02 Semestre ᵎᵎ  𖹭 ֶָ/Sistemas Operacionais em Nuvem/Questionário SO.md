Dadas as afirmações sobre o uso da virtualização para um usuário comum e um projetista de sistemas operacionais, analise as afirmativas.

I) Para o usuário comum o ambiente criado pela virtualização permite uma segurança completa dos diversos recursos do sistema

II) Mesmo tendo segurança completa não há compartilhamento direto dos recursos. Duas técnicas podem ser implementadas para compartilhar o recurso: compartilhar discos permitindo assim o compartilhamento de arquivos ou definir uma rede de máquinas virtuais podendo cada uma enviar informações pela rede.

III) Para um usuário avançado (desenvolvedor de sistema operacional) a etapa de virtualização permite eliminar problemas complexos de desenvolvimento pelo fato de que testes do sistema que se está trabalhando é em uma máquina virtual e não física.

**Todas as alternativas são verdadeiras.**  
Apenas a I e III são verdadeiras.  
Apenas a III é verdadeira.  
Apenas a II é verdadeira.  
Apenas a I é verdadeira.
