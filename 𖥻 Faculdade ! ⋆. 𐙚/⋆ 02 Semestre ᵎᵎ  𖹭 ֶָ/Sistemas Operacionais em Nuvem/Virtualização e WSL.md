## WSL

O Windows Subsystem for Linux (WSL) é um recurso do Windows que permite que você execute um  
ambiente Linux na sua máquina Windows, sem a necessidade de uma máquina virtual separada ou  
dual boot.

O WSL foi projetado para fornecer uma experiência contínua e produtiva para  
desenvolvedores que desejam usar o Windows e o Linux ao mesmo tempo.

### WSL 1 e WSL 2

Suas principais diferenças são uso do Kernel Linux real dentro de uma vm gerenciada, suporte para compatibilidade total de chamadas de sistema e desempenho nos sistemas operacionais.

O WSL2 executa distribuições Linux como contêineres isolados dentro da VM gerenciada.
