## **O que é infraestrutura em nuvem?**

⋆ A infraestrutura em nuvem **é um conjunto de recursos de hardware e software que fornecem serviços de computação na Internet.**

****⋆ **Infraestrutura em nuvem** refere-se aos componentes físicos e de software que compõem um ambiente de computação em nuvem.

---

## Finalidade de um Sistema Operacional:

⋆ A finalidade de um sistema operacional (SO) é **gerenciar os recursos de um dispositivo e facilitar a interação entre o usuário e o hardware**.

⋆ Ele oculta as particularidades do hardware e cria uma interface que permite ao usuário interagir com o dispositivo.

**As principais funções do SO são:**

→ Gerenciar os recursos do dispositivo, como memória RAM, discos, teclado, mouse, impressora, entre outros;

→ Interpretar os comandos do usuário;

→ Organizar arquivos em disco.

---

## BIOS:

⋆ **É a sigla para Basic Input/Output System**.

⋆ É um programa de firmware que inicializa o computador e gerencia o fluxo de dados entre o sistema operacional e os dispositivos conectados.

⋆ Quando o computador é ligado, a BIOS realiza uma série de testes para verificar o hardware e, em seguida, localiza o sistema operacional.
